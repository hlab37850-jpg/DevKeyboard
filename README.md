# DevKeyboard

لوحة مفاتيح Android للمطورين، مبنية لسير عمل Termux + GitHub، مع محرك ترجمة حقيقي.

## الميزات
- تخطيط إنجليزي وعربي كامل مع Shift و Caps Lock وضغط مطول للهمزات والتشكيل.
- صف أدوات الطرفية: Esc / Tab / Ctrl / Alt / الأسهم.
- اختصارات تحكم: Ctrl+C, Ctrl+D, Ctrl+Z, Ctrl+L, Ctrl+A, Ctrl+E, Ctrl+U, Ctrl+K.
- صفحتا رموز برمجية.
- مقتطفات أوامر قابلة للتحرير مع علامة %% لموضع المؤشر.
- سجل حافظة محلي (30 عنصراً) مع تثبيت وحذف.
- ترجمة عبر MyMemory (بدون مفتاح) أو LibreTranslate (خادم خاص).
- ذاكرة ترجمة محلية لتقليل استهلاك الإنترنت.
- قاموس تقني محلي كبديل محدود عند انقطاع الشبكة.
- وضع آمن تلقائي في حقول كلمات المرور.

## البناء
يتم البناء بالكامل عبر GitHub Actions:

    Actions -> Build DevKeyboard APK -> Run workflow

الناتج: Artifact باسم `DevKeyboard-debug-apk`.

## التثبيت
1. نزّل الـ APK وثبّته.
2. افتح تطبيق DevKeyboard.
3. اضغط "تفعيل اللوحة في النظام" وفعّلها.
4. اضغط "اختيار اللوحة الآن" واختر DevKeyboard.

## ملاحظات الترجمة
- MyMemory خدمة مجانية محدودة الحصة يومياً. إضافة بريد صحيح في الإعدادات ترفع الحصة.
- LibreTranslate يتطلب خادمًا عاملاً، وبعض الخوادم العامة تتطلب مفتاح API.
- لا يتم إرسال أي نص إلى الشبكة إلا عند ضغط زر "ترجم".
